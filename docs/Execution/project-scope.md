# 项目范围与验收边界

本项目名称为“市政设施巡检与维修平台”。当前开发以仓库内 `docs/municipal-facility-ops.md` 为唯一执行手册，需求分析文档作为业务需求和验收依据。

## 覆盖范围

- 设施：路灯、交通信号、道路破损、井盖、人行道、排水、垃圾设施和绿化设施。
- 角色：调度员、巡检员、维修人员、供应商、管理员和审计人员。
- 闭环：问题上报、分诊、设施识别、SLA 判断、巡检、派工、维修、验收和审计。
- 数据：公开数据、合成数据、用户上传数据必须在数据和界面中分别标识。

## MVP 验收边界

- 至少 5 个独立 Agent。
- RAG 上传、解析、切块、向量化、检索和原文展示链路。
- 工单状态流转、人工确认、幂等和审计。
- Docker Compose 在全部功能完成后执行，当前 Step 1～Step 5 阶段不启动 Compose。
