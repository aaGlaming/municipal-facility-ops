# 03 Search Service MCP

- **首次使用步骤：** Step 7
- **接入状态：** 可用于公开资料检索
- **项目用途：** 查找政府公开数据、Open311、维护规范和官方字段说明。
- **计划交付物：** 来源 URL、数据集 ID、筛选条件、许可说明和资料缺口记录。
- **安全边界：** 搜索结果必须下载到本地、计算 SHA256、登记 manifest 后才能进入 RAG。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
