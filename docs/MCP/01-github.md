# 01 GitHub MCP

- **首次使用步骤：** Step 2
- **接入状态：** 建议安装，当前仓库已通过 Git CLI 管理
- **项目用途：** 管理仓库、Issue、Pull Request、代码审查、Release、标签和验收问题。
- **计划交付物：** 提交记录、Issue/PR 关联、发布说明和验收证据索引。
- **安全边界：** 不保存工单业务事实，不直接执行派工、验收、关闭或权限变更。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
