# 08 Codex Security MCP

- **首次使用步骤：** Step 23
- **接入状态：** 建议用于 Step 28～31，当前需安装
- **项目用途：** 辅助检查密钥泄露、依赖风险、工具越权、提示注入和发布配置。
- **计划交付物：** 安全扫描报告、严重级别、复现步骤、修复状态和回归证据。
- **安全边界：** 扫描结果必须人工复核，不能自动修改高风险业务逻辑或批准现场操作。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
