# 07 Dropbox MCP

- **首次使用步骤：** Step 14
- **接入状态：** 可选，需用户授权
- **项目用途：** 接入供应商文档和历史维修附件作为候选 RAG 资料。
- **计划交付物：** 文件路径、权限、版本、哈希、来源类型和保留期限。
- **安全边界：** 仅接入明确授权目录，图片和附件必须通过内容安全与脱敏检查。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
