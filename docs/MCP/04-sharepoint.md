# 04 SharePoint MCP

- **首次使用步骤：** Step 14
- **接入状态：** 可选，需用户授权和站点权限
- **项目用途：** 读取组织内部维护手册、SLA、应急预案和验收资料。
- **计划交付物：** 文档来源、权限范围、版本、生效日期和同步记录。
- **安全边界：** 只读优先；不能绕过 SharePoint 权限，失效或未授权文档不得入库。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
