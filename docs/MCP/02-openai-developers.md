# 02 OpenAI Developers MCP

- **首次使用步骤：** Step 3
- **接入状态：** 建议安装，使用官方文档来源
- **项目用途：** 核对 OpenAI-compatible API、Embedding、工具调用、模型参数和 SDK 版本。
- **计划交付物：** 模型配置说明、接口兼容记录、版本和迁移注意事项。
- **安全边界：** 不保存 API Key，不代替项目模型适配层，不直接执行 Agent 业务写操作。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
