# 11 Teams MCP

- **首次使用步骤：** Step 28
- **接入状态：** 可选，需组织授权
- **项目用途：** 向运维、调度和审计团队发送告警与验收通知。
- **计划交付物：** 通知模板、收件范围、审批链接、事件 ID 和发送审计。
- **安全边界：** 通知不能替代人工确认接口，不能在 Teams 中直接改变工单状态。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
