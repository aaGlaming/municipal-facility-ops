# 05 Google Drive MCP

- **首次使用步骤：** Step 14
- **接入状态：** 可选，需用户授权
- **项目用途：** 作为内部规范和供应商资料的受控 RAG 来源。
- **计划交付物：** 文件 ID、来源用户、版本、哈希、同步时间和删除策略。
- **安全边界：** 不把共享盘全量导入；按目录和文档权限过滤，并保留原文定位信息。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
