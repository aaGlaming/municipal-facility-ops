# 10 Slack MCP

- **首次使用步骤：** Step 28
- **接入状态：** 可选，需工作区授权
- **项目用途：** 发送服务异常、安全评测、人工确认和发布状态通知。
- **计划交付物：** 通知规则、频道权限、事件 ID、发送结果和失败重试记录。
- **安全边界：** 只发送脱敏摘要和链接，不发送密钥、完整报修人信息或未授权地址。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
