# 09 Figma MCP

- **首次使用步骤：** Step 25
- **接入状态：** 可选，需连接 Figma 项目
- **项目用途：** 读取工作台、Agent 状态、RAG 结果和人工确认的设计标注。
- **计划交付物：** 页面、组件、设计 token、交互状态和实现映射。
- **安全边界：** 设计稿只作为前端参考，不决定后端权限和业务状态。
- **失败回退：** MCP 不可用时使用本地缓存、人工确认或项目内置脚本；业务核心流程不得因 MCP 单点故障而失去审计能力。
- **关联计划：** [Step 6～36 增强实施计划](../Execution/step06-36-plan.md)
